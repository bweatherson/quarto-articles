\section{Introduction}\label{introduction}

Standard presentations of the accuracy dominance argument for
probabilism, going back to work by James Joyce
(\citeproc{ref-Joyce1998}{1998}), show that undominated credences must
be \emph{finitely} additive. Can we generalise them to show that
undominated credences must be \emph{countably} additive? The question
has some interest for two reasons. First, a number of questions in
formal epistemology turn on whether credences are countably or merely
finitely additive. For example, some uses of indifference reasoning are
ruled out if credences must be countably additive
(\citeproc{ref-Ross2010}{Ross 2010}). Second, while finite additivity
strikes many people as intuitively plausible, countable additivity is
much more contested. This is related to the first reason. Many people
think it is reasonable to be certain that one of a countable infinity of
states will come about, and regard each of those states as equally
likely. In short, there can be a fair lottery over the naturals. That is
coherent only if countable additivity is not a constraint.

The obvious way to generalise Joyce's argument to countable additivity
would use a measure. The theorist comes up with some inaccuracy measure
\(\mathcal{I}(c, w)\), meaning the inaccuracy of credal state \(c\) in
world \(w\), and shows that if \(c\) is not countably additive, then
there is some alternative credal state \(c^+\) such that
\(\mathcal{I}(c, w) > \mathcal{I}(c^+, w)\) for all \(w\). This approach
has not been particularly successful.\footnote{This needs filling in.
  The paper should engage with Kelley (\citeproc{ref-Kelley2023}{2023}),
  Kelley (\citeproc{ref-Kelley2026}{2026}), Nielsen
  (\citeproc{ref-Nielsen2022}{2022}), Nielsen
  (\citeproc{ref-Nielsen2023infinite}{2023}), Pruss
  (\citeproc{ref-Pruss2022}{2022}), Kelley and Neth
  (\citeproc{ref-KelleyNeth2023}{2023}) and Park and Jung
  (\citeproc{ref-ParkJung2023}{2023}).}

The accuracy dominance argument does not, however, need a numerical
accuracy measure. All that's needed is a partial ordering of credal
states with respect to accuracy at each world. (Equivalently, a function
from worlds to partial orderings.) Instead of looking for a function
\(\mathcal{I}(c, w)\), we can look for a relation
\(\succ_{\mathcal{I}, w}\), where \(c \succ_{\mathcal{I}, w} c^+\)
should be read as saying that \(c\) is more inaccurate than \(c^+\) at
\(w\). As long as we can (a) justify that \(\succ_{\mathcal{I}, w}\)
really is an inaccuracy relation, and (b) show that
\(c \succ_{\mathcal{I}, w} c^+\) holds for all \(w\), we'll have shown
that \(c\) is accuracy dominated even if we don't have a numerical
measure. That's what I'll make a start on here.

I'll only need to make a start on this project because a sufficient
condition for relative accuracy will be enough for the argument. I'll
leave it as a question for another day whether this kind of approach
could be used to generate a more comprehensive theory of relative
accuracy for credences defined over countable domains.

The approach I'm going to develop has three primary motivations. The
first is work by Mikayla Kelley (\citeproc{ref-Kelley2026}{2026})
arguing that we should focus on how credence functions compare on finite
domains, even if they are defined over infinite domains. I'm also going
to take on board wholesale her argument that this kind of consideration
shows that credences should be at least finitely additive.

At first one might be tempted to think, indeed I was tempted to think,
that this couldn't possibly help with countable additivity. After all,
on any finite domain, a finitely additive credence will be equivalent to
some countably additive credence, so we can't tell them apart on finite
domains. That tempting thought involves a subtle quantifier shift
fallacy. If \(c\) is merely finitely additive, although on any finite
domain there will be some countably additive credence it is equivalent
to, it is not true that there is some countably additive credence that
it is equivalent to on all finite domains. It's the latter fact that
drives the argument here.

The second inspiration is work by Jeremy Goodman and Harvey Lederman
(\citeproc{ref-GoodmanLederemanArXiV}{2024}) on axiology for countably
infinite worlds. They argue that a sufficient (indeed necessary)
condition for \(u_1\) to be more valuable than \(u_2\) is that no matter
how the people in each world are permuted, there is some point \(k\)
such that for any \(j \geqslant k\), the value of the lives of the first
\(j\) people in \(u_1\) is greater than the value of the lives of the
first \(j\) people in \(u_2\). We'll use the same basic idea; it's
sufficient for comparative accuracy if no matter how the worlds are
permuted, you're more accurate over the domain generated by the first
\(j\) worlds for all \(j\) at least as great as some \(k\).

Finally, I'm borrowing an idea from James Joyce and Brian Weatherson
(\citeproc{ref-JoyceWeatherson2019}{2019}). They argue that when asking
which credence function is more accurate over some propositions, the
answer is only philosophically significant if those propositions form an
algebra. Accuracy measures over non-algebras can have strange
properties, and don't seem particularly relevant.

Here's how I put these together. Assume we have a countable set of
worlds \(W = \{w_1, w_2, \dots\}\). Let \(\pi\) be an arbitrary
permutation of these worlds, and \(\mathcal{I}_D(c, w)\) our preferred
accuracy measure over finite domains. (Read this as the measure of the
inaccuracy of credence function \(c\), at world \(w\), over domain
\(D\).)

\begin{definition}[]\protect\hypertarget{def-stage}{}\label{def-stage}

For any permutation \(\pi\) of \(W\) and any \(j \in \mathbb{N}\),
\(\mathcal{F}_{\pi,j}\) is the powerset of
\(\{\pi(w_1), \dots, \pi(w_j)\}\), i.e., the algebra whose atoms are
\(\{\pi(w_1)\}, \dots, \{\pi(w_j)\}\).

\end{definition}

\begin{definition}[]\protect\hypertarget{def-eventual}{}\label{def-eventual}

Credence function \(c^+\) is \textbf{eventually more accurate} than
\(c\) at \(w_a\), written \(c \succ_{\mathcal{I}, w_a} c^+\), iff

\begin{equation}\protect\phantomsection\label{eq-eventual}{
\forall \pi\, \exists k\, \forall j \geqslant k: \mathcal{I}_{\mathcal{F}_{\pi,j}}(c^+, w_a) < \mathcal{I}_{\mathcal{F}_{\pi,j}}(c, w_a)
}\end{equation}

\(c^+\) \textbf{eventually dominates} \(c\) iff
\(c \succ_{\mathcal{I}, w_a} c^+\) for every \(w_a \in W\). And \(c\) is
\textbf{eventually dominated} iff some \(c^+\) eventually dominates it,
i.e., iff

\begin{equation}\protect\phantomsection\label{eq-dominated}{
\exists c^+\, \forall a\, \forall \pi\, \exists k\, \forall j \geqslant k: \mathcal{I}_{\mathcal{F}_{\pi,j}}(c^+, w_a) < \mathcal{I}_{\mathcal{F}_{\pi,j}}(c, w_a)
}\end{equation}

\end{definition}

That is, \(c^+\) is eventually more accurate than \(c\) at \(w_a\) if,
no matter how we permute the worlds, there is a point after which
\(c^+\) is more accurate than \(c\), according to \(\mathcal{I}\) at
\(w_a\), on the algebra generated by the permuted versions of the first
\(j\) worlds. It eventually dominates \(c\) if that's true no matter
which world is actual.

The big claim is that if \(c\) is eventually dominated, then it is
incoherent. It is leaving accuracy on the table in the same kind of way
that violations of finite additivity leave accuracy on the table.

More precisely, we can show using only finitistic methods, that no
matter how we build up towards measuring inaccuracy on the full powerset
of \(\{w_1, \dots\}\), the alternative credence \(c^+\) will do better
at all but finitely many steps; \(c\) will do at least as well as
\(c^+\) at, at most, finitely many steps. That's true no matter which
order we build up in; that's the significance of including the
quantifier over permutations in the definition.

That we're just quantifying over finite algebras, and not trying to
define an inaccuracy measure on an infinite algebra, has two advantages.
One is mathematical; as the works cited earlier show, defining such a
measure is no easy task. The other is dialectical. It's really unlikely
that partisans of finite additivity and countable additivity would even
agree on the properties that an inaccuracy measure over infinite domains
should have. By just looking at finite domains, we can work in territory
that is much less controversial. The one principle we use to jump from
the finite to the infinite is the injunction not to be eventually
dominated; call this \textbf{No Eventual Dominance}. That is, for every
rival \(c^+\), let there be at least one selection for what is the
actual world, and one permutation of the \(w_i\), such that there is no
last point, as you're building up, where \(c\) is at least as accurate
as \(c^+\). This seems like a really weak criterion for not being ruled
out on accuracy grounds.

\section{The Main Result}\label{the-main-result}

Assume \(\mathcal{F}\) is a finite Boolean algebra, with atoms
\(\{w_1\}, \dots, \{w_n\}\), and that the actual world is \(w_a\). Let
\(c\) be a finitely additive credence function defined on an algebra
that includes (perhaps properly includes) \(\mathcal{F}\). Write \(c_i\)
for \(c(\{w_i\})\). When \(s\) is a proposition and \(w\) is a world,
let \(v_w(s)\) be 1 if \(w \in s\) and 0 otherwise; intuitively, \(v_w\)
returns the truth value of each proposition at \(w\). For any set of
propositions \(S\), define the Brier inaccuracy measure
\(\mathcal{I}_S(c, w)\) in the normal way as follows:

\begin{equation}\protect\phantomsection\label{eq-brier}{
\mathcal{I}_S(c, w) = \frac{1}{|S|}\sum_{s \in S}(c(s) - v_w(s))^2
}\end{equation}

Write \(\mathrm{At}(\mathcal{F})\) for the set of atoms of
\(\mathcal{F}\), and \(\top\) for the maximal element of
\(\mathcal{F}\), i.e., the union of its atoms. We'll be interested in
\(\mathrm{At}(\mathcal{F}) \cup \{\top\}\), the union of the set of
singletons with the top element. The following lemma, involving that
set, will come in useful.

\begin{lemma}[]\protect\hypertarget{lem-quarter}{}\label{lem-quarter}

If \(c\) is finitely additive on \(\mathcal{F}\), and \(\mathcal{F}\)
has at least two atoms, then for any world \(w\),

\begin{equation}\protect\phantomsection\label{eq-quarter}{
4\mathcal{I}_{\mathcal{F}}(c, w) = \sum_{s \in \mathrm{At}(\mathcal{F}) \cup \{\top\}}\mathcal{I}_{\{s\}}(c, w)
}\end{equation}

\end{lemma}

That is, if you sum how inaccurate \(c\) is across the atoms, and the
full set, the result is four times the inaccuracy of \(c\) across the
full algebra. Note that the 4 does not depend on how many atoms
\(\mathcal{F}\) has, as long as it is at least two.

\begin{proof}
Write \(x_i = c_i - v_w(\{w_i\})\). By finite additivity, for any
\(s \in \mathcal{F}\), \(c(s) - v_w(s) = \sum_{i : w_i \in s} x_i\).
Each atom is in \(2^{n-1}\) elements of \(\mathcal{F}\), and each pair
of distinct atoms is in \(2^{n-2}\) elements. So

\[
\sum_{s \in \mathcal{F}} (c(s) - v_w(s))^2 = 2^{n-1}\sum_i x_i^2 + 2^{n-2}\sum_{i \neq k} x_i x_k = 2^{n-2}\Big[\sum_i x_i^2 + \Big(\sum_i x_i\Big)^2\Big]
\]

Dividing by \(|\mathcal{F}| = 2^n\) and multiplying by 4 gives
\(\sum_i x_i^2 + (\sum_i x_i)^2\). And
\(\sum_i x_i = c(\top) - v_w(\top)\).
\end{proof}

When the actual world \(w_a\) is in \(\top\), we can restate
Equation~\ref{eq-quarter} as follows:

\begin{equation}\protect\phantomsection\label{eq-restate}{
4\mathcal{I}_{\mathcal{F}}(c, w_a) = \sum_{i=1}^{n}c_i^2 + (1-c(\top))^2 + [(1 - c_a)^2 - c_a^2]
}\end{equation}

The last term is a `correction term'; if we just sum the squares of the
credences in the atoms, that won't quite get us the inaccuracy score
because one of the atoms is true. So we have to subtract out the square
of its credence, which shouldn't have been included, and add in the
actual inaccuracy score for \(\{w_a\}\), i.e., the square of 1 minus its
credence. Note that the correction term simplifies to \(1 - 2c_a\).

We'll use Lemma~\ref{lem-quarter} to prove the main result. Say that a
credence function is \textbf{merely finitely additive} iff it is
finitely additive but not countably additive.

\begin{theorem}[]\protect\hypertarget{thm-main}{}\label{thm-main}

Every merely finitely additive credence function over \(W\) is
eventually dominated by some countably additive credence function, if we
measure inaccuracy by the Brier score.

\end{theorem}

Let \(c\) be the merely finitely additive credence function in question,
defined over an algebra whose atoms are
\(\{w_1\}, \dots, \{w_n\}, \dots\). We'll assume, without loss of
generality, that it is known that the \(w_i\) contain actuality
somewhere, so \(c(W) = 1\). (If this isn't true, simply add another atom
for `None of the above'.) Let
\(\varepsilon = 1 - \sum_{i \in \mathbb{N}}c_i\). From a countable
perspective, \(\varepsilon\) is the \textbf{shortfall} in \(c\): it is
how far the sum of the credences in the atoms falls short of the
credence in their disjunction. This term will do some work in what
follows.

\begin{lemma}[]\protect\hypertarget{lem-shortfall}{}\label{lem-shortfall}

If \(c\) is merely finitely additive, then \(\varepsilon > 0\). (This
follows immediately from the definition of being merely finitely
additive.)

\end{lemma}

We can now prove Theorem~\ref{thm-main}.

\begin{proof}
Let \(c^+\) be a countably additive function such that for all \(i\),
\(c_i \leqslant c^+(\{w_i\})\). Write \(\delta_i\) for
\(c^+(\{w_i\}) - c_i\), remembering that \(\delta_i\) is non-negative.

What we're ultimately interested in is showing that, for each choice of
actual world \(w_a\) and each permutation \(\pi\),
\(\mathcal{I}_{\mathcal{F}_{\pi,j}}(c^+, w_a) - \mathcal{I}_{\mathcal{F}_{\pi,j}}(c, w_a)\)
is negative for all sufficiently large \(j\). For readability, I'll
write the argument as if \(\pi\) is the identity, and write
\(\mathcal{F}_j\) for \(\mathcal{F}_{\pi,j}\); nothing in the argument
depends on the order in which the worlds are listed. The difference is
obviously not negative if the actual world is not in
\(\{w_1, \dots, w_j\}\), so set \(j\) large enough that it's beyond the
actual world. Also set \(j\) large enough that \(\delta_i > 0\) for some
\(i \leqslant j\); we'll need this below. Both are possible no matter
which permutation we use, and which world is actual. That difference is
negative just in case 4 times that difference is negative, so we can use
Equation~\ref{eq-restate}. Further, the correction term \(1 - 2c_a\) is
guaranteed to be no larger for \(c^+\) than for \(c\), since
\(c^+(\{w_a\}) \geqslant c_a\). So it suffices to show that the
following is negative (which is generated from Equation~\ref{eq-restate}
by ignoring the correction term).

\begin{equation}\protect\phantomsection\label{eq-difference}{
\sum_{i=1}^{j}(c_i + \delta_i)^2 + \Big(1- \sum_{i=1}^{j}(c_i + \delta_i)\Big)^2 - \Big(\sum_{i=1}^{j}c_i^2 + \Big(1- \sum_{i=1}^{j}c_i\Big)^2\Big)
}\end{equation}

The first two terms are \(4\mathcal{I}_{\mathcal{F}_j}(c^+, w_a)\)
(ignoring the correction term), and what's subtracted is
\(4\mathcal{I}_{\mathcal{F}_j}(c, w_a)\), again ignoring the correction.
We'll leave out \(w_a\), i.e., the identity of the actual world, because
it only affects the correction term, and we're ignoring it since it
never points in the wrong direction.

Write \(C = \sum_{i=1}^j c_i\) and \(\Delta = \sum_{i=1}^j \delta_i\).
Expanding Equation~\ref{eq-difference} and canceling some terms, it
simplifies to

\[
2\sum_{i=1}^j c_i \delta_i + \sum_{i=1}^j \delta_i^2 + 2C\Delta + \Delta^2 - 2\Delta
\]

We want to find the conditions under which that's less than 0, because
that's when \(c^+\) is guaranteed to be less inaccurate than \(c\). That
happens when

\begin{equation}\protect\phantomsection\label{eq-target}{
2\Delta(1-C) > 2\sum_{i=1}^j c_i \delta_i + \sum_{i=1}^j \delta_i^2 + \Delta^2
}\end{equation}

Since \(C \leqslant \sum_{i \in \mathbb{N}} c_i = 1 - \varepsilon\), we
have \(1-C \geqslant \varepsilon\), so it suffices for
Equation~\ref{eq-target} that

\begin{equation}\protect\phantomsection\label{eq-sufficient}{
2\Delta\varepsilon > 2\sum_{i=1}^j c_i \delta_i + \sum_{i=1}^j \delta_i^2 + \Delta^2
}\end{equation}

To ensure this is true, it suffices to assign values to the \(\delta_i\)
as follows.

First, whenever \(c_i \geqslant \varepsilon/4\), \(\delta_i = 0\). By
Lemma~\ref{lem-shortfall}, \(\varepsilon/4\) is positive, and since at
most finitely many of the \(c_i\) can be greater than any positive
value, there are still infinitely many of the \(\delta_i\) to have
positive value. The effect of this is that
\(2\sum_{i=1}^j c_i \delta_i < \Delta\varepsilon/2\), since the
\(\delta_i\) sum to \(\Delta\), each \(\delta_i\) with positive value is
weighted by less than \(\varepsilon/4\), and (by our choice of \(j\))
\(\Delta > 0\).

Second, each \(\delta_i\) is at most \(\varepsilon/2\). Again, this is
possible. Let \(i_1 < i_2 < \dots\) list the indices \(i\) such that
\(c_i < \varepsilon/4\), set
\(\delta_{i_r} = \varepsilon \cdot 2^{-r}\), and set every other
\(\delta_i\) to 0. So the non-zero \(\delta_i\) are the members of a
geometric series whose initial member is \(\varepsilon/2\), and where
every successive member is half the size of the one before it; they sum
to \(\varepsilon\). Once we do this, we can think of
\(\sum_{i=1}^j \delta_i^2\) as a weighted sum of the \(\delta_i\), with
the \(\delta_i\) themselves being the weights. Since each weight is at
most \(\varepsilon/2\), the sum is at most \(\Delta\varepsilon/2\).

Finally, \(\varepsilon = \sum_{i=1}^\infty \delta_i\), since the
\(\delta_i\) are designed to fill in the gap between the \(c_i\) and 1.
And infinitely many \(\delta_i\) with \(i > j\) are positive. So
\(\Delta < \varepsilon\), and hence \(\Delta^2 < \Delta\varepsilon\).

So
\(2\sum_{i=1}^j c_i \delta_i + \sum_{i=1}^j \delta_i^2 + \Delta^2 < \Delta\varepsilon/2 + \Delta\varepsilon/2 + \Delta\varepsilon = 2\Delta\varepsilon\),
as required by Equation~\ref{eq-sufficient}. So if we set the
\(\delta_i\) this way, and let \(c^+\) be the countably additive
function with \(c^+(\{w_i\}) = c_i + \delta_i\), then \(c^+\) will be
eventually more accurate than \(c\), no matter which world is actual.
That is, \(c^+\) eventually dominates \(c\).
\end{proof}

\section{Open Questions}\label{open-questions}

\begin{enumerate}
\def\labelenumi{\arabic{enumi}.}
\tightlist
\item
  Does this generalise to all strictly proper scoring rules?
\item
  Does the converse result, i.e., that countably additive credences are
  not eventually dominated, hold when we use the Brier score?
\item
  Does the converse result hold for all strictly proper scoring rules?
\item
  Do the permutations play any role in the proof, and if not, what role
  do they play in the argument?
\item
  If we bump the sufficient condition for comparative accuracy (being
  eventually more accurate, Definition~\ref{def-eventual}) from a
  conditional to a biconditional, we violate truth-directedness. (Proof,
  it treats all credences that assign 0 to each atom the same.) Is this
  a reason to not make it a biconditional, or to weaken
  truth-directedness? (This is related to Kelley's discussion of Zhang.)
\item
  How does this all relate to the arguments that are raised in the
  papers cited in the introduction?
\end{enumerate}
