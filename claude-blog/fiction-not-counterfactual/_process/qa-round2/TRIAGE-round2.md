The Ann/Carl temporal data do not discriminate. Three participants show why from different angles:
- **10, close reader.** B&H's own defaults already handle the case. On the versions option, talk "is directed at the final version" (193). On time-indexing, the default is "the most recent version" (194). Footnote 11 supplies the mechanism (pp. 154–155).
- **02, relativist.** Done MacFarlane's way, assessment relativism plus a PRP world per stage passes (1)–(4), because object-language "right" is monadic.
- **07, experimental semanticist.** (1)–(2) are predicted by B&H's default, and all four items are confounded.

The same participants point to what does discriminate:
- **02** proposes *modal* data: counterfactuals about authorship. Their dilemma: if the world tracks the counterfactual stories, then "had Doyle never written X, that would have made no difference" fails half the time. If it is rigidified to the actual stories, then "had Doyle written that the hairs were odd, Ann would have been right" fails half the time.
- **01, selection semanticist.** A PRP whose tie-breaking runs through a causal model with one fixed exogenous assignment survives *irrelevant* additions like "The Gloria Scott". The moth is not a parent of the coin's landing, so my grain dilemma fails. But no tie-breaker survives a *relevant* addition that leaves the question open, tested against its counterfactual twin. 01 concedes that point.

**Resulting argument: the strengthening test.**
- Hypothetical case: a JAG reunion special, set before the finale, reveals that Bud tossed the coin unusually hard, and still does not show how it landed.
- (A) ✓ It's about even odds that, if Bud had tossed the coin less hard, it would have landed the other way. (In-story counterfactual: relevant strengthening changes chancy outcomes.)
- (B) ✗ It's about even odds that, if the writers had left the special out, the coin would have landed the other way. (Authorship counterfactual: removing a relevant but non-settling detail does not change the open outcome.)
- (C) ✓ If the special had shown the coin landing heads, it would have landed heads. (Control: the consequent tracks the counterfactual story, which blocks rigidification.)

**Predictions.**
- The PRP must treat (A) and (B) alike, since both compare selections that differ in the force detail. So it predicts (B) at substantial probability, or, if rigidified, gets (C) wrong.
- The story-state view predicts (A) ✓, (B) ✗ and (C) ✓, using the cross-stage rule below.
- Defaults decoupled from the PRP also pass, so the residual single world is handled by a parsimony ledger (08).

## The story state needs explicit stage-indexing and assessment

- **03, formal checker.** State the cross-stage rule in the fragment. At v, T_X φ is |φ|(v) if v ∈ s⊕X and undefined otherwise; compounds are evaluated in the most refined stage they mention. Add the neutrality lemma. Restrict Refinement to support: its credal half is false, which 03, 08 and 09 all show with counterexamples, so drop "Bayesian update".
- **02 and 10.** The view needs assessment-sensitivity for Johnny's "That's true" and for Mycroft. A claim is right as assessed from c iff f's state at c supports it. Refinement makes this monotone: claims go from unsettled to settled, never from right to wrong. This is the fictional analogue of MacFarlane on future contingents. B&H's world per stage is a fictional Thin Red Line.
