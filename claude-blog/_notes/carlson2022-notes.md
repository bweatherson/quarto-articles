# Carlson 2022, "On Some Impossibility Theorems in Population Ethics" (OUP Handbook, pp. 204–225) — read 2026-10-03 via Chrome/UM proxy

Core claims (from full text):
- Target: Arrhenius's sixth theorem. Carlson does NOT question the five conditions ("they will not be questioned here"). He attacks the background assumption Finite Fine-Grainedness (FFG).
- Key sentence: "Arrhenius's proof shows that no population axiology satisfies the exact versions of his five adequacy conditions, given that the order of welfare levels assumed in the proof is fine-grained and A-discrete." — i.e. Carlson takes the theorem to be TRUE given A-discreteness (integer levels). Our result refutes exactly this.
- Distinguishes A-discreteness (finitely many levels between any two) from S-discreteness (every level has an adjacent one); argues Arrhenius's arguments support only S-discreteness; FFG implies (Proto-)Archimedeanness, which many deny (Parfit's century of ecstasy vs drab eternity; Griffin).
- §4–5: "non-Archimedean totalism": welfare levels (h,l) ∈ I×I lexicographic (superior/inferior components); very high iff h ≥ m; very low positive only if h = 0, l > 0; very negative iff h ≤ n < 0; populations ranked by lexicographic total. Verifies informal ED, GNEP, NE, WNS, WQA (WQA in ORIGINAL quantifier order; the view also satisfies WQA*). This is the view Thornley 2021 calls Lexical Totalism ("As Thomas (2018) and Carlson (forthcoming) note").
- Consequence: very negative lives have h < 0, marginal lives h = 0, so misery + any marginal lives has h < 0 → worse than empty population. ✓ (our §4 claim holds for Carlson's view too.)
- §7 + appendix: non-Archimedean totalism also satisfies the conditions of T1, T4, T5 (with FFG weakened); violates Inequality Aversion (T2, T3), which Carlson argues is not compelling and is a misnomer.
- Does not mention Thomas's Lemma 1.3 gap (chapter dates from 2014–15 seminars).
